## 总结

1. 首先是LED模式跳转，比如，模式4->模式1，判断最后两个灯是不是18.

2. LED模式写好之后就是数码管模式1，模式1经按键6跳转到模式2，按下3次在回到模式0

3. 3目运算符：条件语句？结果1：结果2。如果条件为真，则执行结果1；否则执行结果2.

4. 高位熄灭写法，i的初始值为数据的最高位

   ```c
   while(Seg_Buf[i] == 0)
   {
       Seg_Buf[i] = 10;
       i++;
   }
   ```

5. 按下按键设置数据并保存退出的通用逻辑

   ```c
   case 6://设置按键
       if(Seg_Disp_Mode == 0)
       {
           for(i = 0;i<4;i++)
           {
               Led_Time_Set[i] = Led_Time_Data[i];//读取当前数据，新变量是防止在设置时未保存退出修改原数据
           }
           Seg_Disp_Mode = 1;//跳转到参数设置界面
       }
       else if(Seg_Disp_Mode == 1)
       {
           Set_Flag ^= 1;//选中要设置的数据部分
           if(Set_Flag == 0) //第三次按下S6保存数据
           {
               for(i = 0;i<4;i++)
                   Led_Time_Data[i] = Led_Time_Set[i];//保存数据并退出
               Seg_Disp_Mode = 0;
           }
   
       }
   ```

6. 按键长按处理

   ```C
   //判断Key_Old是否为当前按键的键码，只要不松手会一直等于键码
   if(Key_Old == 4 && Seg_Disp_Mode == 0)
   {
       Data_Disp_flag = 1;////显示数据
   }
   ```

7. 选中某个单元并闪烁的逻辑

   1. 首先定义一个标志位Set_Flag,在按键处理中取反；
   2. 定义一个闪烁标志位Star_Flag,在中断函数中达到闪烁周期取反。eg：以 0.8 秒为间隔亮灭。即闪烁周期为0.4s

   ```c
   if(Set_Flag == 0)
       {
           Seg_Buf[0] = Star_Flag?13:10; //"-"
           Seg_Buf[1] = Star_Flag?Led_Mode_Set+1:10;
       }
       else
       {
           Seg_Buf[2] = Star_Flag?Led_Time_Set[Led_Mode_Set] / 1000 % 10 : 10;
           Seg_Buf[3] = Star_Flag?Led_Time_Set[Led_Mode_Set] / 100 % 10 : 10;
           Seg_Buf[4] = Star_Flag?Led_Time_Set[Led_Mode_Set] / 10 % 10 : 10;
           Seg_Buf[5] = Star_Flag?Led_Time_Set[Led_Mode_Set] / 1 % 10 : 10;			
       }
   ```
