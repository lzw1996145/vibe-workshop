# 蓝桥杯嵌入式设计大赛入门指南

蓝桥杯是全国性的信息技术竞赛，其中嵌入式设计大赛是热门赛道之一。

## 竞赛简介

蓝桥杯嵌入式设计大赛主要考察：
- STM32 外设开发能力
- 传感器应用能力
- 程序设计与调试能力
- 现场应变能力

## 硬件平台

比赛使用 **CT117E-M4 开发板**，基于 STM32G4 系列芯片。

### 板载资源

| 外设 | 用途 |
|------|------|
| LCD 显示屏 | 显示界面 |
| LED 指示灯 | 状态指示 |
| 按键 | 用户输入 |
| 蜂鸣器 | 声音提示 |
| 传感器接口 | 外接模块 |

## 题型分析

### 客观题（30分）
- 单选题 + 判断题
- 考察嵌入式基础知识

### 设计题（70分）
- 4-5 个功能模块
- 需要现场编程实现
- 包含功能要求和评分标准

## 常用代码模板

```c
// 按键扫描模板
uint8_t Key_Scan(void) {
    if (KEY1 == 0) return KEY1_PRES;
    if (KEY2 == 0) return KEY2_PRES;
    return 0;
}

// 定时器中断模板
void TIM3_IRQHandler(void) {
    if (TIM_GetITStatus(TIM3, TIM_IT_Update) != RESET) {
        // 用户代码
        TIM_ClearITPendingBit(TIM3, TIM_IT_Update);
    }
}
```

## 比赛注意事项

1. **先看题目**：理解每个模块的分值和难度
2. **合理分配时间**：先做有把握的题目
3. **注意评分标准**：确保功能完整实现
4. **代码规范**：添加必要注释
