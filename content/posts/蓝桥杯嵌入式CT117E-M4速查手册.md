## 一、硬件基础

### 1.1 LED/KEY/LCD引脚复用

```
PC0~7 ──────────┬── LCD数据总线（D0~D7）
                │
                └── 锁存器PD2控制切换

PC8~15 ──────── LED控制（LED1~8）

PD2 ─────────── 锁存器使能（高电平有效）

PB0,1,2 ─────── KEY输入（B1,B2,B3）
PA0 ─────────── KEY输入（B4）
```

### 1.2 GPIO配置速查

| 外设 | 引脚 | 模式 | 上拉/下拉 |
|------|------|------|-----------|
| LED | PC8~15 | Output Push Pull | - |
| KEY | PB0,1,2 | GPIO Input | **Pull-up** |
| KEY | PA0 | GPIO Input | **Pull-up** |
| 锁存器 | PD2 | Output Push Pull | - |
| LCD数据 | PC0~7 | Output Push Pull | - |
| LCD控制 | PB5(WR) | Output | - |
| LCD控制 | PB8(RS) | Output | - |
| LCD控制 | PA8(RD) | Output | - |

### 1.3 LED/KEY/LCD三角关系

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| LED与LCD引脚冲突 | PC0~7共用 | **锁存器PD2**隔离 |
| LCD操作导致LED闪烁 | 锁存器未关闭 | LCD操作完关闭锁存器 |
| LED状态错乱 | 锁存器脉冲太短 | BSRR→BRR连续操作 |

## 二、LED驱动

### 2.1 核心数据结构

```c
uint8_t ucled[8] = {0};  // LED状态数组，0=灭，1=亮
```

### 2.2 LED数组映射

| 数组索引 | ucled[0] | ucled[1] | ucled[2] | ... | ucled[7] |
|----------|----------|----------|----------|-----|----------|
| LED编号 | LED1 | LED2 | LED3 | ... | LED8 |
| 位位置 | Bit7(MSB) | Bit6 | Bit5 | ... | Bit0(LSB) |

### 2.3 底层驱动 ⚠️易错

```c
void led_disp(uint8_t *ucled)
{
    uint8_t temp = 0x00;
    static uint8_t temp_old = 0xff;   // static保持上次值

    // 打包：ucled[0]→LED1(最高位)，ucled[7]→LED8(最低位)
    for(int i = 0; i < 8; i++)
        temp |= (ucled[i] << (7 - i));   // ⚠️ 左移(7-i)，不是(i)

    if(temp != temp_old)   // 状态改变才刷新
    {
        GPIOC->ODR &= 0x00ff;           // 清空PC8~15
        GPIOC->ODR |= ~(temp << 8);     // ⚠️ 必须<<8
        GPIOD->BSRR = 0x01 << 2;        // 开锁存器
        GPIOD->BRR  = 0x01 << 2;        // 关锁存器
        temp_old = temp;
    }
}
```

### 2.4 LED任务函数

```c
// scheduler.c 中：{led_proc, 1, 0},  // 1ms周期
void led_proc(void)
{
    led_disp(ucled);
}
```

### 2.5 LED操作示例

```c
// 点亮LED1、LED3、LED5
ucled[0] = 1; ucled[2] = 1; ucled[4] = 1;

// LED2取反
ucled[1] ^= 1;

// 流水灯（定时调用）
for(int i=0; i<8; i++) {
    ucled[i] = (i == pos) ? 1 : 0;
}
```

### ⚠️ LED易错点

| 错误写法 | 正确写法 | 说明 |
|----------|----------|------|
| `temp << 0` | `temp << 8` | 操作高字节 |
| `ucled[i] << i` | `ucled[i] << (7-i)` | 位序对应 |
| 只写ODR | `&=0x00ff`后`\|=` | 先清后设 |

## 三、KEY驱动

### 3.1 按键定义

| 按键 | 引脚 | 键值 | 说明 |
|------|------|------|------|
| B1 | PB0 | 1 | 上方从左到右 |
| B2 | PB1 | 2 | |
| B3 | PB2 | 3 | |
| B4 | PA0 | 4 | 独立按键 |

### 3.2 全局变量

```c
uint8_t key_val = 0;   // 当前键值
uint8_t key_down = 0;  // 按下瞬间=1
uint8_t key_up = 0;    // 释放瞬间=1
uint8_t key_old = 0;   // 上次键值
```

### 3.3 读取键值

```c
uint8_t key_read(void)
{
    uint8_t temp = 0;
    if(HAL_GPIO_ReadPin(GPIOB, GPIO_PIN_0) == GPIO_PIN_RESET) temp = 1;
    if(HAL_GPIO_ReadPin(GPIOB, GPIO_PIN_1) == GPIO_PIN_RESET) temp = 2;
    if(HAL_GPIO_ReadPin(GPIOB, GPIO_PIN_2) == GPIO_PIN_RESET) temp = 3;
    if(HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_0) == GPIO_PIN_RESET) temp = 4;
    return temp;
}
```

### 3.4 按键处理

```c
// scheduler.c 中：{key_proc, 10, 0},  // 10ms周期
void key_proc(void)
{
    key_val = key_read();

    // 检测边沿
    key_down = key_val & (key_old ^ key_val);  // 下降沿
    key_up   = ~key_val & (key_old ^ key_val); // 上升沿

    key_old = key_val;
}
```

### 3.5 使用示例

```c
void key_proc(void)
{
    key_proc();  // 先调用，更新key_down/key_up

    if(key_down == 1) {        // B1按下
        ucled[0] ^= 1;         // LED1取反
    }
    if(key_down == 2) {        // B2按下
        ucled[1] ^= 1;         // LED2取反
    }
    if(key_down == 3) {        // B3按下
        ucled[2] ^= 1;         // LED3取反
    }
    if(key_down == 4) {        // B4按下
        ucled[3] ^= 1;         // LED4取反
    }
}
```

## 五、程序框架

### 5.1 初始化顺序（严格按此）

```
HAL_Init()
  ↓
SystemClock_Config()    // CubeMX生成
  ↓
MX_GPIO_Init()          // CubeMX生成
  ↓
MX_USART1_UART_Init()   // 串口初始化（如使用）

  ↓
```

### 5.3 任务调度器

#### 核心结构体

```c
typedef struct {
    void (*task_func)(void);  // 任务函数
    uint32_t rate_ms;         // 执行周期(ms)
    uint32_t last_run;        // 上次执行时间
} task_t;
```

#### 任务数组（scheduler.c）

```c
static task_t scheduler_task[] = {
    {led_proc,   1,    0},   // LED: 1ms
    {key_proc,  10,    0},   // KEY: 10ms
    {lcd_proc, 100,    0},   // LCD: 100ms
    {uart_proc, 20,    0},   // UART: 20ms（如果使用）
    {adc_proc,  50,    0},   // ADC: 50ms（如果使用）
};
```

#### 初始化

```c
void scheduler_init(void)
{
    task_num = sizeof(scheduler_task) / sizeof(task_t);
}
```

#### 运行函数

```c
void scheduler_run(void)
{
    for(uint8_t i = 0; i < task_num; i++)
    {
        uint32_t now_time = HAL_GetTick();

        if(now_time >= scheduler_task[i].rate_ms + scheduler_task[i].last_run)
        {
            scheduler_task[i].last_run = now_time;
            scheduler_task[i].task_func();
        }
    }
}
```

### 5.4 添加新任务（三步走）

**步骤1**：编写任务函数

```c
// xxx_app.c
void xxx_proc(void)
{
    // 你的任务逻辑
}
```

**步骤2**：注册任务

```c
// scheduler.c - scheduler_task[] 中添加
{xxx_proc, 20, 0},   // 例如20ms周期
```

**步骤3**：包含头文件

```c
// bsp_system.h 中添加
#include "xxx_app.h"
```

### 5.5 周期选择参考

| 任务类型 | 推荐周期 | 说明 |
|----------|----------|------|
| LED刷新 | 1~10ms | 快速响应 |
| 按键扫描 | 10ms | 消抖需求 |
| LCD刷新 | 50~200ms | 慢速显示 |
| 串口处理 | 10~20ms | 防丢数据 |
| ADC采样 | 50~100ms | 视精度而定 |

### ⚠️ 调度器易错点

| 错误现象 | 原因 | 解决方案 |
|----------|------|----------|
| 任务不执行 | rate_ms=0 | 周期必须>0 |
| 任务卡顿 | 任务内有阻塞 | 禁止HAL_Delay() |
| 编译报错task_num | 未调用scheduler_init() | main.c中添加 |

| 功能 | TX | RX |

### 6.3 底层代码（usart.c）

```c
/* USER CODE BEGIN 0 */
#include "string.h"
typedef struct __FILE FILE;

uint16_t uart_rx_index = 0;
uint32_t uart_rx_ticks = 0;
uint8_t uart_rx_buffer[128] = {0};
/* USER CODE END 0 */

void MX_USART1_UART_Init(void)
{
  // ... CubeMX生成代码 ...

  /* USER CODE BEGIN USART1_Init 2 */
  HAL_UART_Receive_IT(&huart1, uart_rx_buffer, 1);
  /* USER CODE END USART1_Init 2 */
}

int fputc(int ch, FILE *str)
{
    HAL_UART_Transmit(&huart1, (uint8_t *)&ch, 1, 10);
    return ch;
}
```

### 6.4 逻辑层代码（uart_app.c）

```c
void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart)
{
    if(huart->Instance == USART1)
    {
        uart_rx_ticks = uwTick;
        uart_rx_index++;
        HAL_UART_Receive_IT(&huart1, &uart_rx_buffer[uart_rx_index], 1);
    }
}

void uart_proc(void)
{
    if(uart_rx_index == 0) return;

    if(uwTick - uart_rx_ticks > 100)  // 超时100ms
    {
        printf("user data:%s\n", uart_rx_buffer);
        memset(uart_rx_buffer, 0, uart_rx_index);
        uart_rx_index = 0;
        huart1.pRxBuffPtr = uart_rx_buffer;
    }
}
```

### 6.5 使用示例

```c
// 发送
printf("Hello World\n");
printf("ADC: %.2f V\n", adc_value[0]);

// 接收（自动在uart_proc中处理）
```

## 七、ADC模数转换

### 7.1 基础参数

| 项目 | 说明 |
|------|------|
| 分辨率 | 12位（0~4095） |
| 参考电压 | 3.3V |
| 通道数 | 2路（ADC1、ADC2） |

### 7.2 引脚

| ADC | 引脚 | 输入源 |
|-----|------|--------|
| ADC1 | PC0 | 滑动变阻器R37 |
| ADC2 | PC1 | 滑动变阻器R38 |

### 7.3 底层代码（main.c）

```c
uint32_t dma_buff[2][30];  // DMA缓冲区

// 启动ADC DMA
HAL_ADC_Start_DMA(&hadc1, (uint32_t *)&dma_buff[0][0], 30);
HAL_ADC_Start_DMA(&hadc2, (uint32_t *)&dma_buff[1][0], 30);
```

### 7.4 逻辑层代码（adc_app.c）

```c
#include "adc_app.h"

uint32_t dma_buff[2][30];
float adc_value[2];

void adc_proc(void)
{
    uint32_t sum0 = 0, sum1 = 0;

    for(int i = 0; i < 30; i++)
    {
        sum0 += dma_buff[0][i];
        sum1 += dma_buff[1][i];
    }

    // 转换为电压值
    adc_value[0] = (float)sum0 / 30 * 3.3f / 4096;
    adc_value[1] = (float)sum1 / 30 * 3.3f / 4096;
}
```

### 7.5 电压换算公式

```c
adc_value = sum / N * 3.3f / 4096
// N = 采样次数（30）
```

### ⚠️ ADC易错点

| 错误现象 | 原因 | 解决方案 |
|----------|------|----------|
| ADC不更新 | 未启动DMA | 添加HAL_ADC_Start_DMA |
| 固定4095 | 输入超量程 | 检查硬件 |
| 波动大 | 未取平均 | 多次采样 |

| 端口 | 引脚 | 用途 | 方向 |
|------|------|------|------|
| **PC** | 0~7 | LCD数据 | 输出 |
| **PC** | 8~15 | LED控制 | 输出 |

```
GPIO → PC8~15:    Output Push Pull
GPIO → PB0,1,2:   GPIO Input (Pull-up)

ADC1 → PC0: 12-bit, Continuous, DMA
```

## 九、常见错误汇总

### 9.1 LED相关

| 错误 | 原因 | 正确写法 |
|------|------|----------|
| LED全亮 | 锁存器未操作 | BSRR+BRR连续 |
| 位序错乱 | 左移位数错误 | `<< (7-i)` |
| 高字节污染 | 忘记`&=0x00ff` | 先清后设 |

### 9.2 KEY相关

| 错误 | 原因 | 正确写法 |
|------|------|----------|
| 无响应 | 模式配下拉 | 改为上拉输入 |
| 边沿失效 | 未更新key_old | 必须每次更新 |
| 抖动误触 | 周期太短 | KEY=10ms |

### 9.3 LCD相关

| 错误 | 原因 | 正确写法 |
|------|------|----------|
| 花屏 | LED/LCD冲突 | 操作完关锁存 |
| 溢出 | 缓冲区太小 | String[21] |
| 闪烁 | 刷新太快 | LCD≥50ms |

### 9.4 UART相关

| 错误 | 原因 | 正确写法 |
|------|------|----------|
| 卡死 | 未勾选微库 | Use MicroLIB |
| 乱码 | 波特率不匹配 | 9600 |
| 回调不进入 | 未开NVIC | 启用中断 |

### 9.5 ADC相关

| 错误 | 原因 | 正确写法 |
|------|------|----------|
| 不更新 | 未Start_DMA | 添加启动代码 |
| 4095 | 超量程 | 检查输入 |
| 波动大 | 未取平均 | 30次采样 |

### 9.6 调度器相关

| 错误 | 原因 | 正确写法 |
|------|------|----------|
| 任务不跑 | 周期为0 | rate_ms>0 |
| 卡死 | 任务内阻塞 | 禁止HAL_Delay |
| 报错 | 未初始化 | scheduler_init() |
