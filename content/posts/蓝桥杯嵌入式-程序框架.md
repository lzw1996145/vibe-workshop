## 一、系统初始化

### 1.1 初始化流程（严格按此顺序）

```
HAL_Init()              // HAL库初始化
  ↓
SystemClock_Config()    // 系统时钟配置（CubeMX生成）
  ↓
MX_GPIO_Init()          // GPIO初始化（CubeMX生成）
  ↓
LCD_Init() + LCD_Set... // LCD初始化（如果使用）
  ↓
scheduler_init()        // 调度器初始化
  ↓
while(1) { scheduler_run(); }  // 进入任务循环
```

### 1.2 统一头文件 bsp_system.h

```c
#ifndef _BSP_SYSTEM_H
#define _BSP_SYSTEM_H

#include "stdio.h"
#include "stdarg.h"
#include "string.h"

#include "lcd.h"
#include "main.h"
#include "system.h"
#include "scheduler.h"
#include "led_app.h"
#include "key_app.h"
#include "lcd_app.h"

extern uint8_t ucled[];
#endif
```

> **作用**：一站式包含所有外设头文件，避免重复include

### 1.3 系统初始化 system.c

```c
void system_init(void)
{
    // 将PC8~15设置为高电平（LED默认熄灭）
    GPIOC->ODR |= 0xff00;

    // 锁存器使能脉冲
    GPIOD->BSRR = 0x01 << 2;  // PD2置位
    GPIOD->BRR  = 0x01 << 2;  // PD2复位
}
```

> **说明**：LED默认熄灭状态 + 锁存器初始化

## 二、任务调度器

### 2.1 核心数据结构

```c
// 任务控制块
typedef struct {
    void (*task_func)(void);  // 任务函数指针
    uint32_t rate_ms;         // 执行周期（毫秒）
    uint32_t last_run;        // 上次执行时间
} task_t;

// 全局变量：任务数量
uint8_t task_num;
```

### 2.2 任务数组定义 ⚠️易错

```c
static task_t scheduler_task[] = {
    {led_proc,  1,   0},   // LED刷新：1ms周期
    {key_proc, 10,   0},   // 按键扫描：10ms周期
    {lcd_proc, 100,  0},   // LCD刷新：100ms周期
    // 新任务添加格式：{函数名, 周期ms, 0},
};
```

| 参数 | 含义 | 推荐值 |
|------|------|--------|
| `task_func` | 要执行的任务函数 | - |
| `rate_ms` | 执行周期（毫秒） | LED=1, KEY=10, LCD=100 |
| `last_run` | 上次执行时间（初始化=0） | 固定填0 |

### 2.3 调度器初始化

```c
void scheduler_init(void)
{
    // 自动计算任务数量
    task_num = sizeof(scheduler_task) / sizeof(task_t);
}
```

### 2.4 调度器运行函数 ⚠️易错

```c
void scheduler_run(void)
{
    for(uint8_t i = 0; i < task_num; i++)
    {
        uint32_t now_time = HAL_GetTick();  // 当前系统时间(ms)

        // 判断是否到达执行时刻
        if(now_time >= scheduler_task[i].rate_ms + scheduler_task[i].last_run)
        {
            // 更新上次执行时间
            scheduler_task[i].last_run = now_time;

            // 执行任务函数
            scheduler_task[i].task_func();
        }
    }
}
```

> **原理**：时间片轮询，非阻塞，每个任务按各自周期独立执行

## 三、如何添加新任务

### 3.1 步骤一：编写任务函数

在对应app文件中添加：

```c
// xxx_app.c
void xxx_proc(void)
{
    // 你的任务逻辑
}
```

```c
// xxx_app.h
#ifndef _XXX_APP_H
#define _XXX_APP_H

void xxx_proc(void);
#endif
```

### 3.2 步骤二：注册到任务数组

```c
// scheduler.c - static task_t scheduler_task[] 中添加：
{xxx_proc, 20, 0},   // 例如：20ms周期
```

### 3.3 步骤三：包含头文件

```c
// bsp_system.h 中添加：
#include "xxx_app.h"
```

### 3.4 周期选择参考

| 任务类型 | 推荐周期 | 说明 |
|----------|----------|------|
| LED刷新 | 1~10ms | 快速响应 |
| 按键扫描 | 10ms | 消抖需要 |
| LCD刷新 | 50~200ms | 慢速显示 |
| 串口处理 | 10~20ms | 避免数据丢失 |
| ADC采样 | 20~100ms | 取决于精度 |
| 状态机 | 10ms | 固定周期 |

## 四、常见错误与注意事项

### 4.1 常见错误

| 错误现象 | 原因 | 解决方案 |
|----------|------|----------|
| 任务不执行 | 周期设为0 | `rate_ms`必须>0 |
| 任务执行太快 | `last_run`未更新 | 确保赋值语句位置正确 |
| 编译报错task_num未定义 | 未调用`scheduler_init()` | main.c中添加 |
| 任务卡顿 | 任务函数内有阻塞 | 任务必须快速返回 |

### 4.2 注意事项

| 要点 | 说明 |
|------|------|
| ✅ 任务函数内禁止阻塞 | 如`delay_ms()`、`while()`死等 |
| ✅ 任务应快速执行 | 执行时间 << 周期时间 |
| ✅ 共享资源需保护 | 多任务访问同一变量时注意 |
| ✅ 周期不宜过小 | 最小建议5ms，避免CPU过载 |

### 4.3 任务函数规范

```c
// ✅ 正确：快速执行，立即返回
void led_proc(void)
{
    led_disp(ucled);
}

// ❌ 错误：包含阻塞延时
void bad_task(void)
{
    HAL_Delay(100);  // 阻塞！会导致整个调度器卡住
    // ...
}
```

## 五、完整程序框架

### 5.1 main.c 标准模板

```c
#include "main.h"
#include "gpio.h"
#include "bsp_system.h"

int main(void)
{
    HAL_Init();
    SystemClock_Config();
    MX_GPIO_Init();

    // 外设初始化
    LCD_Init();
    LCD_Clear(Black);
    LCD_SetTextColor(White);
    LCD_SetBackColor(Black);

    // 系统初始化
    system_init();

    // 调度器初始化
    scheduler_init();

    // 主循环
    while(1)
    {
        scheduler_run();
    }
}
```

## 六、原理图相关

### 6.1 LED与LCD引脚复用

| 引脚 | LED功能 | LCD功能 | 解决方案 |
|------|---------|---------|----------|
| PC0~7 | LED低8位 | LCD数据总线 | **锁存器PD2** |
| PC8~15 | LED高8位 | 复用 | - |

### 6.2 锁存器时序

```
PD2 ─┐
     ├──> 锁存器使能，控制LED/LCD切换
PD2 ─┘
     ↑         ↑
   BSRR       BRR
   置位      复位
```

> **关键**：LCD操作时不影响LED状态，必须通过锁存器控制

## 七、扩展：多文件调度器（可选）

如果任务很多，可以分文件管理：

```c
// scheduler.c - 主调度器
#include "scheduler.h"

extern task_t led_task[];
extern task_t key_task[];
extern task_t lcd_task[];

static task_t* task_groups[] = {
    led_task,
    key_task,
    lcd_task
};

void scheduler_run(void)
{
    for(uint8_t g = 0; g < 3; g++) {
        uint8_t num = sizeof(task_groups[g]) / sizeof(task_t);
        for(uint8_t i = 0; i < num; i++) {
            // ... 同样逻辑
        }
    }
}
```
