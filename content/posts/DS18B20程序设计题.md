# 考点

## 数据流转

### **进入设置界面**

```markdown
编辑区 = 生效区
```

确保用户看到的起始值是当前有效参数。

------

### **用户编辑**

```
编辑区自由修改
```

不影响系统行为。

------

### **用户确认（如按“保存/退出/OK”）**

```
如果 编辑区合法：
       生效区 = 编辑区
否则：
       忽略修改
```

### 代码示例

```c
//由于题目要求需要点击切换才能保存，∴首先定义显示数组与实际控制数组
unsigned char Parametor[2] = {30,20};//参数数据储存数组
unsigned char Parametor_Ctrl[2] = {30,20};//真实参数控制数组
case 12: //界面切换界面
        Seg_Disp_Mode = Seg_Disp_Mode==0?1:0;
        if(Seg_Disp_Mode == 0) //参数设置界面跳转到温度显示界面
        {
            Parametor_Index = 0;
            if(Parametor[0]>Parametor[1]) //设置参数合法性
            {
                Parametor_Ctrl[0] = Parametor[0];
                Parametor_Ctrl[1] = Parametor[1];
            }

        }
        if(Seg_Disp_Mode == 1) //温度显示界面跳转到参数设置界面
        {
            Parametor[0] = Parametor_Ctrl[0];
            Parametor[1] = Parametor_Ctrl[1];
        }
break;
```

## 长短按

题目：长按超过500ms，快速加减1；500ms之内，按一次+1

思路：定义一个计时变量与计时开始标志位，如果按下按键，开始计时。

```c
	//按下开始计时
	if(Seg_Disp_Mode == 1) //仅在参数设置界面有效
	{
		if(Key_Down == 14 || Key_Down == 15)
			Time_Flag = 1;
	}
	if(Count_500ms < 500) //短按
	{
		if(Key_Up == 14) //+1
		{
			Count_500ms = Time_Flag = 0;
			if(++Parametor[Parametor_Index] == 71)
				Parametor[Parametor_Index] = 10;
		}
		if(Key_Up == 15)//-1
		{
			Count_500ms = Time_Flag = 0;
			if(--Parametor[Parametor_Index] == 9)
				Parametor[Parametor_Index] = 70;
		}
	}
	else //长按
	{
		if(Key_Old == 14) //+1
		{		
			if(++Parametor[Parametor_Index] == 71)
				Parametor[Parametor_Index] = 10;
		}
		if(Key_Old == 15)//-1
		{			
			if(--Parametor[Parametor_Index] == 9)
				Parametor[Parametor_Index] = 70;
		}
		if(Key_Up == 14 || Key_Up == 15)//抬起按键
		{
			Count_500ms = Time_Flag = 0;
		}
	}
```
